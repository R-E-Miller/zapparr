# NVIDIA SHIELD TV (2015, 2017, the 2019 tube and the 2019 Pro), SHIELD Experience 9 on Android TV 11.
#
# match: manufacturer=NVIDIA
#
# `debloat.py plan` (with no list named) uses this list on top of android-tv.txt, which already has
# Google's telemetry and preloaded apps. One package per line; everything after # is a comment.
# Nothing is uninstalled: `python tools/debloat.py restore` re-enables all of it.
#
# Sources, cited next to each group:
#   [CYT n/3]   CleanYourTV's tested SHIELD lists (MIT license, (c) 2026 Gathin), checked 2026-10-30:
#               n of nvidia-shield-tv-2017, nvidia-shield-tv-2019 and nvidia-shield-tv-pro-2019.
#               https://github.com/Gathin23/cleanyourtv/tree/main/examples
#   [SHIELD]    bharvey88, debloating four SHIELDs across three generations over ADB:
#               https://gist.github.com/bharvey88/c211c6ca1d9e5f1379b204bf75067275
#
# Never disabled here, as both sources say (debloat.py protects them): the remote and controller
# pairing (com.nvidia.blakepairing, com.nvidia.bluetooth.*, com.nvidia.shieldtech.*,
# com.nvidia.ControllerMapper, com.nvidia.remotelocator, com.nvidia.irtuner), the SHIELD TV phone app
# (com.nvidia.shield.remote.server), AI upscaling, picture and sound (com.nvidia.NvCPLSvc,
# com.nvidia.nvaudiosvc, com.nvidia.avsync, com.nvidia.overscancomp), com.nvidia.shieldservice,
# com.nvidia.packagemanagerservice, keychain and com.android.se (soft-bricked units), and
# com.google.android.tvrecommendations (the phone app's keys stop working after a reboot without it).

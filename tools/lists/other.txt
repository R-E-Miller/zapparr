# `debloat.py plan` (with no list named) uses this list when `debloat.py probe` can't tell what the box
# is, together with any vendor or model list whose "match:" line fits. It is short on purpose: only
# Google's telemetry and the print spooler, which behave the same on every box that has them. On a box

# your own (see the "match:" lines in the vendor lists), and read `plan` before `apply`.
#
# One package per line; everything after # is a comment. Packages that aren't installed are skipped,
# and nothing is uninstalled: `python tools/debloat.py restore` re-enables all of it.

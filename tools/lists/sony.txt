# Sony BRAVIA sets with Android TV or Google TV.
#
# match: manufacturer=Sony
# match: brand=Sony

# `debloat.py plan` (with no list named) uses this list on top of the generic list for the platform.
# One package per line; everything after # is a comment. Nothing is uninstalled:
# `python tools/debloat.py restore` re-enables all of it.
#
# Sources, cited next to each group:
#   [CYT n/41]  CleanYourTV's 41 tested Sony lists (examples/sony-*; MIT license, (c) 2026 Gathin),
#               checked 2026-10-30: https://github.com/Gathin23/cleanyourtv
#   [UV]        udeshvirk/sony-bravia-launcher's debloat-list.txt, tested on a BRAVIA 4K VH2 (KD-55X80J):
#               https://github.com/udeshvirk/sony-bravia-launcher/blob/master/debloat-list.txt
#
# Never disabled here (debloat.py protects them): com.sony.dtv.tvx and tvlin (Live TV and every HDMI
# input), com.sony.dtv.tvinput.*, Bravia Sync (HDMI-CEC), remote pairing and keys, the Input menu
# (smartui), Sony's system services and settings, all com.mediatek.* and com.realtek.*, and
# com.sony.dtv.b2b.hotelmode: TV Settings opens blank without its provider (CYT sony-kd-55x8000c),
# although other lists, [UV] among them, disable it.
#
# probe and set-home show this on a Sony set:

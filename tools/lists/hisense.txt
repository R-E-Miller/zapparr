# `debloat.py plan` (with no list named) uses this list on top of the generic list for the platform.

# `python tools/debloat.py restore` re-enables all of it.

# Source: CleanYourTV's tested Hisense lists (MIT license, (c) 2026 Gathin), checked 2026-10-30:

#   [CYT n/11]  all eleven Android TV and Google TV ones
#   https://github.com/Gathin23/cleanyourtv/tree/main/examples
#
# Never disabled here (debloat.py protects them): Live TV and the inputs (com.vt.tv.tvcenter,
# com.vt.tv.input, com.vt.source.*), the TV services (com.vt.tvservice, com.vt.avmiddleware,
# com.vt.tvplayer, com.vt.tv.commonui, com.vt.tv.smartservice), com.vt.tv.smartsense and
# com.hisense.tv.smartsense (one set went to Android Recovery without them), com.vt.tv.aiot*,
# com.vt.udpserver (casting and phone-remote discovery), all com.mediatek.*.
